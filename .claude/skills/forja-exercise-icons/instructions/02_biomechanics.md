# 02 — Biomechanics interpretation rules

## Golden rule
Biomechanical accuracy is more important than artistic improvisation.

Do not convert the exercise into a different variation just because it is more common.

## Analyze the reference for
1. exact movement / exercise variant;
2. body support setup (standing, seated, prone, reclined, on incline bench, chest-supported, etc.);
3. torso angle;
4. bench angle;
5. shoulder position;
6. upper-arm path;
7. elbow angle;
8. forearm angle;
9. wrist orientation;
10. hand state;
11. lower-body setup;
12. foot placement;
13. machine layout;
14. line of resistance;
15. perspective.

## Preserve exactly when relevant
- bench angle;
- body orientation;
- cable height;
- machine side placement;
- attachment method;
- crossed vs uncrossed cable routing;
- unilateral vs bilateral version;
- pronated / neutral / supinated or empty-fist hand state;
- support points.

## If the reference is partially obstructed
Infer only the missing details that are necessary to complete the same exercise plausibly.
Do not invent a different exercise.

## If multiple references are attached
Use them together to resolve ambiguity.
Prefer the clearest frame for geometry and the others for confirmation.
