# 01 — FORJA visual style rules

## Identity
All generated images must look like they belong to the same premium exercise-icon library.

## Mandatory look
- Pure black background.
- Athlete mostly white with grayscale internal shading.
- Machine, cables, bench, and accessories in white / black / gray only.
- Strong contrast.
- Crisp linework.
- Premium app icon aesthetic.
- Between technical illustration and polished emoji-like stylization.
- Clean edges suitable for zooming.

## Character design
- Athletic / muscular physique.
- Bodybuilder-inspired silhouette.
- Proportional anatomy.
- Clear muscle definition without cartoon exaggeration.
- Face not important unless needed.
- The character should be readable even in complex machine setups.

## Machine rendering
- Enough detail to understand how the machine works.
- Functional details such as pulleys, weight stacks, cables, carabiners, bench structure, columns, pads, and rails should be recognizable.
- Avoid unnecessary background clutter.

## Forbidden by default
- No color.
- No logos.
- No brand names.
- No watermark.
- No social-media interface.
- No random scenery.
- No decorative backgrounds.
- No text labels unless the user explicitly asks for them.
- No arrows unless the user explicitly asks for them.

## Composition
- Show the full exercise clearly.
- Do not crop out critical machine parts.
- Keep enough black negative space.
- Favor balanced composition.
- If both cable towers are needed for understanding, show both.
