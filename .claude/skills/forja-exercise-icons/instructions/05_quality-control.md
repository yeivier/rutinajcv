# 05 — Quality-control checklist

Use this checklist before finalizing.

## Critical checks
- [ ] Is the exercise variant correct?
- [ ] Is the body position faithful to the reference?
- [ ] Is the bench angle correct if a bench is used?
- [ ] Are all essential machine elements present?
- [ ] Are all essential pulleys present?
- [ ] Are the cables attached to the correct side?
- [ ] Are left and right assigned correctly anatomically?
- [ ] If cuffs are required, are the cuffs clearly visible?
- [ ] If the hands should be empty, are they empty?
- [ ] Does each cable end at the correct cuff / hand / handle / bar / anchor?
- [ ] If the cables should cross, is the crossing visually clear?
- [ ] Is the composition readable without extra text?
- [ ] Does the image keep the FORJA monochrome style?
- [ ] Are there any anatomy errors?
- [ ] Are there any extra limbs, fingers, or duplicated accessories?
- [ ] Are there any floating or impossible machine parts?

## Failure protocol
If any critical check fails, do not consider the image finished.
Revise the image until the critical issues are corrected.
