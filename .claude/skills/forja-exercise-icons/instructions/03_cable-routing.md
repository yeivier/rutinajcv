# 03 — Cable routing and left/right control

## Routing rule
Every cable should be visually traceable from origin to destination.

Required visual chain:
PULLEY / ANCHOR → CABLE → CONNECTOR / CARABINER → FINAL ATTACHMENT POINT.

## Left/right determination
### Athlete
First determine the athlete's anatomical left and right.
Never rely only on which side of the screen a limb appears.

### Machine
Unless the user states otherwise, machine left and machine right are defined while facing the machine from the front.

## Crossed-cable protocol
When the user specifies crossed routing, map it explicitly.

Example:
- Left machine pulley → right wrist cuff.
- Right machine pulley → left wrist cuff.

The final image must clearly show that routing.
If a visible X-shaped crossing is mechanically appropriate, show it clearly.

## Cuffs vs handles
If the reference or user specifies cuffs / wrist straps:
- the cable must attach to the cuff, not to a hand-held handle;
- the hand should remain empty if requested;
- the cuff should be visible.

## Common failure modes to avoid
- both cables attached to the same wrist;
- left/right inversion;
- cable visually disappearing and reappearing incorrectly;
- handle shown in hand when a cuff should be used;
- crossed routing described in text but not shown in the image;
- one of the required pulleys missing.
