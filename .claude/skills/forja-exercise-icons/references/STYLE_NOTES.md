# STYLE_MASTER usage notes

`STYLE_MASTER.png` is the canonical FORJA style anchor.

Use it only as a visual-style guide for:
- monochrome black-and-white treatment;
- line weight and clarity;
- muscular character style;
- machine rendering language;
- premium exercise-icon feel;
- balance between simplicity and detail.

Do **not** assume that the specific exercise shown in `STYLE_MASTER.png` must be reused for future requests.
For future requests:
- STYLE_MASTER = style only.
- User attachment(s) = biomechanics and exercise structure.
